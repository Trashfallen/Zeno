# Zeno

[English version](README.md)

Голос, видео, трансляция экрана и чат на двоих напрямую между компьютерами (WebRTC, P2P). Своего сервера нет. Windows, закрытая бета.

## Возможности

- **Друзья соединяются сами.** Один раз обменяться кодами дружбы, дальше программы находят друг друга через зашифрованный канал пары на публичных серверах (MQTT и ntfy). Запасные пути: короткий код из 6 знаков или длинный код через любой мессенджер.
- **Голосовой звонок.** Opus до 128 кбит/с, эхоподавление, автоусиление, шумовой гейт с авто-порогом, push-to-talk по всей системе, выбор устройств.
- **Шумодав на выбор.** RNNoise (легкий), DeepFilterNet3, DPDFNet (чище всех и тяжелее всех), NVIDIA Broadcast (видеокарта RTX, ставится отдельно), стандартный Chromium или выключен. Режим «Передавать только голос»: клавиатура, щелчки и чавканье между фразами в звонок не уходят.
- **Камера и трансляция экрана.** До 1440p 60 к/с со звуком системы, режимы «плавность» и «четкость», H.264 на видеокарте, статистика (кадры, битрейт, кодер, пинг).
- **Чат.** История (у каждого своя зашифрованная копия), «печатает», отметки доставки, файлы и картинки.
- **Громкость и просмотр.** Громкость собеседника и трансляции 0-300%, трансляция во весь экран, сохранение кадра, высота окна звонка меняется мышью.
- **Встроенные приложения** (кнопка «Приложения» в чате):
  - **virtualZeno** - локальная сеть с другом, как Hamachi: адреса 10.77.x.y, ping, LAN-игры, общие папки. Работает, пока запущен у обоих.
  - **ЯГессер** - угадай место по панораме Google или Яндекса: классика, дуэль, канат, ставки и другие режимы. Комната живет в Zeno того, кто запустил, друг играет через канал данных.
  - **TarBitTorrent** - передача больших файлов и папок, хоть 50 ГБ: проверка каждого куска, докачка после обрыва и перезапуска. Раздачу видит только друг, идет напрямую или через Zeno, если напрямую не достучаться.
- **Программа для ПК.** Свое окно, значок в трее, автозапуск, установка с ярлыками, самообновление из релизов GitHub.

## Как устроено

- Сервера Zeno нет. Медиа, сообщения и файлы идут напрямую между двумя ПК. Адрес узнается через публичные STUN, можно указать свой TURN.
- У каждого участника своя пара ключей Ed25519. В коде дружбы - публичный ключ и сертификат беты.
- Предложение соединения подписано ключом отправителя. В нем лежит отпечаток DTLS, поэтому подменить собеседника посередине нельзя.
- Первое соединение открывает только канал данных. Микрофон, камера, экран и звук экрана добавляются потом пересогласованием по этому каналу.
- virtualZeno работает через сетевой адаптер Wintun (драйвер WireGuard). Права администратора нужны один раз: Zeno просит UAC и ставит небольшую службу, которая держит адаптер. Адрес выводится из публичного ключа, пакеты с чужим адресом отправителя отбрасываются. Убрать все - Настройки -> Соединение.

## Технологии

- **Go** - сама программа, сигнализация (MQTT через paho, ntfy по HTTPS), обновления, трей.
- **WebView2** - окно; интерфейс на HTML/JS, звонки и чат на WebRTC из Chromium.
- **pion/webrtc** - дополнительные P2P-соединения на Go для virtualZeno и передачи файлов.
- **anacrolix/torrent** - движок BitTorrent для TarBitTorrent.
- **AudioWorklet + WebAssembly** - шумоподавление; DPDFNet работает в onnxruntime-web.
- **Wintun** - виртуальный сетевой адаптер для virtualZeno.

## Требования

- Windows 10 или 11, x64.
- Microsoft Edge WebView2 Runtime (есть в Windows 11, обычно есть в Windows 10).
- Логин и пароль беты от автора.

## Сборка

Нужен Go (версия в `go.mod`).

```
build.cmd        # dist\Zeno.exe
go test ./...
```
